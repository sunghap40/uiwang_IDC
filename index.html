📝 사고발생 시 최초 문자보고 기준

▶ 일반사고 (자산사업장 안전사고 보고)

1. 사업장명 : 000사업장(0팀) 2. 일시 : 3. 재해정도 : 부상 0명 - 00골절 4. 재해내용 - 누가 : 홍길동 (협력사명, 공종, 성별, 나이) - 어디서 : - 무엇을 : - 어떻게 : 5. 기타 : 보고자 : OOO 소장
* 초기보고: 3시간 이내 (중대재해 30분 이내)

▶ 물적피해사고 (화재 포함)

[자산사업장 OO피해 보고] 1. 사업장명 : 000사업장(0팀) 2. 일시 : 3. 피해정도 - 물적 : (예상 피해금액) 4. 피해내용 - 내용 : (위치, 당사관리유무 등) - 경과 : - 전망 : - 추정 원인 등 5. 기타 : 보고자 : OOO 소장
* 초기보고: 3시간 이내

▶ 발송 기준

- 발송자: 법인장 / 지역장 / 소장이 발송 - 통근사고는 정확한 보고를 위해 통근담당자가 발송 가능

🔄 사고 대응 프로세스

* 업무 상 사망자 또는 6개월 이상 부상자가 동시에 2명 이상 발생한 사고
[초기대응] 사고발생 통보
▶ 협력사 (당사사고 시 당사 수행)
사고자 응급 조치(병원후송) → 사고발생통보(HEC) → 고용노동부 보고 → 환자상태 확인 → 가족연락 → 2차 재해방지/보존
▶ HEC 현장 (소속팀)
최초 보고(본사) → 재해자 상태 확인 및 경과 보고 → 고객사 대응/협의
▶ HEC 본사 (품질안전팀/소속팀)
품질안전팀: 최초보고 (사업본부 임원/안전품질본부)
소속팀: 현장업무 지원, 고객사 대응
[사고조사]
협력사: 사고원인 조사, 재발방지대책 강구, 대외기관 대응
HEC현장: 재발방지대책 강구/이행, 사고보고서 작성(초안)
HEC본사: 재발방지대책 검토, 사고 최종 보고(대표이사 전결)
* 업무에 기인하여 발생한 인명사고(업무 중 교통사고 포함)
[초기대응]
협력사: 병원후송, HEC통보, 2차 재해방지 현장보존
HEC현장: 최초 보고(본사), 대체인력 투입 확인
HEC본사: 품질안전팀 최초보고, 소속팀 상황파악
[사고조사]
HEC현장: 원인조사, 대책강구 및 이행, 사고보고서 초안 작성
HEC본사: 사고 최종 보고 및 이력 관리
* 심혈관계/근골격계 질환 병원치료, 제3자 피해사고, 현장 내 인명사건 등
[초기대응]
협력사: 병원후송, HEC통보, 질병정도 파악, 가족 연락
HEC현장: 최초 보고(본사), 대체 인력 투입 확인
HEC본사: 품질안전팀 상황 전파, 소속팀 상황 파악
[사망 시 특이사항]
협력사: 경찰서 사망자 신고, 대외기관 대응
HEC본사(품질안전팀): 현장 업무 지원(대관업무), 진행경과 보고
HEC본사(소속팀): 현장 업무 지원(고객사 대응), 재발방지대책 이행 지원
